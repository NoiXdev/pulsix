# Searchable selects Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace all 76 native `<select>` elements with one searchable component, and offer creation of the missing object wherever a picker would otherwise dead-end a form.

**Architecture:** One presentational `src/ui/Select.tsx` built on downshift's `useCombobox`, taking `options`/`value`/`onChange` — the shape 73 of the 76 call sites already use, so most migrations are a substitution. Quick-create is a callback the feature owns, never a query, because ESLint forbids `src/ui` from reaching into `src/api`. Two test helpers (`pickOption`, one for Vitest and one for Playwright) absorb the 119 test call sites that drive today's native elements.

**Tech Stack:** React 19 (with the React Compiler), TypeScript, downshift 9.4.0, Tailwind 4, Vitest + Testing Library, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-14-v0.4g-searchable-selects-design.md`

- `src/ui/**` may not import from `src/api/**` except as `import type`. ESLint enforces it; the message cites backlog 3.23.

## Review Focus

Five things the spec implies that a task could ship without noticing, ordered by how likely they are to bite someone. Each has a test assigned to the task that owns the code.

1. **Options still loading.** A picker whose query has not resolved gets `options={[]}`. It must say so rather than render an empty popup that reads as "nothing exists". Pinned in Task 1.
2. **A value with no matching option.** A host still references a credential someone deleted. The native `<select>` rendered blank and silently lied. The new one shows the raw value with a marker and does **not** clear it — clearing would write a destructive change the user never asked for on the next save. Pinned in Task 1.
3. **Filter text left behind.** Typing "acm", then clicking away without choosing, must restore the selected option's label. Leaving "acm" in the box reads as a value that was never selected. Pinned in Task 1.
4. **Escape inside a dialog.** Escape with the list open closes the list only. A second Escape closes the dialog. `ui/dialog.tsx` is a native `<dialog>`, whose `onCancel` fires on Escape — so without this the first Escape throws away the whole form. Pinned in Task 2.
5. **Two options with the same label.** Two credentials named `deploy` of different kinds; two hosts of the same name in different zones. Selecting must commit the right `value`, and the test helper must be able to say which one. Pinned in Task 1 (component) and Task 3 (helper takes `{ value }`).

```tsx
import { useMemo, useState } from 'react';
import { useCombobox } from 'downshift';
import { ChevronDown } from 'lucide-react';
import { cn } from '../lib/utils.ts';

export interface SelectOption {
  value: string;
  label: string;
  /** Secondary text on the row — a credential's kind, a host's zone. */
  hint?: string;
  disabled?: boolean;
}

export interface SelectProps {
  options: SelectOption[];
  value: string;
  onChange: (value: string) => void;
  /** Shown as the first row and as the empty label; its presence is what
   *  lets the field go back to no value at all. */
  placeholder?: string;
  id?: string;
  'aria-label'?: string;
  disabled?: boolean;
  invalid?: boolean;
  create?: { label: string; onSelect: (filterText: string) => void };
}

/** Stands in for "no value" when a placeholder is given: downshift wants
 *  an item, and null already means "nothing is selected". */
const NONE = ' none';

/**
 * Select is the one picker in Pulsix (v0.4g, backlog 1.43). It replaced 76
 * native select elements, and ESLint now fails the build on a new one.
 *
 * Always a combobox, never a plain listbox, and with no threshold that
 * switches between the two: options arrive from queries, so a threshold
 * would let the widget change its shape and its keyboard model while the
 * user is inside it.
 *
 * Presentational, like everything in src/ui: it is handed its options and
 * fetches nothing, and `create` is a callback into the feature that owns
 * the dialog (backlog 3.23, and the ESLint rule that enforces it).
 */
export function Select({
  options, value, onChange, placeholder, id, disabled, invalid, create,
  'aria-label': ariaLabel,
}: SelectProps) {
  const [filter, setFilter] = useState('');

  const rows = useMemo<SelectOption[]>(() => {
    const base = placeholder ? [{ value: NONE, label: placeholder }, ...options] : options;
    const q = filter.trim().toLowerCase();
    if (q === '') return base;
    return base.filter((o) => o.label.toLowerCase().includes(q) || (o.hint ?? '').toLowerCase().includes(q));
  }, [options, placeholder, filter]);

  const selected = options.find((o) => o.value === value) ?? null;
  // Review Focus 2: a value whose option is gone (a deleted credential a
  // host still points at). Showing it is the honest answer; clearing it
  // would write a change nobody asked for on the next save.
  const selectedLabel = selected?.label ?? (value === '' ? (placeholder ?? '') : `${value} (unavailable)`);

  const cb = useCombobox<SelectOption>({
    items: rows,
    itemToString: (item) => item?.label ?? '',
    itemToKey: (item) => item?.value ?? null,
    selectedItem: selected,
    onSelectedItemChange: ({ selectedItem }) => {
      if (!selectedItem || selectedItem.disabled) return;
      onChange(selectedItem.value === NONE ? '' : selectedItem.value);
      setFilter('');
    },
    isItemDisabled: (item) => item.disabled === true,
    stateReducer: (state, { type, changes }) => {
      switch (type) {
        // Review Focus 3: closing without a choice is not a choice. Drop
        // whatever was typed and let the selected label render again.
        case useCombobox.stateChangeTypes.InputBlur:
        case useCombobox.stateChangeTypes.InputKeyDownEscape:
          setFilter('');
          return changes;
        default:
          return changes;
      }
    },
  });

  const open = cb.isOpen && !disabled;

  return (
    <div className="relative">
      <input
        {...cb.getInputProps({
          id,
          'aria-label': ariaLabel,
          disabled,
          onChange: (e) => setFilter((e.target as HTMLInputElement).value),
        })}
        value={open ? filter : selectedLabel}
        placeholder={placeholder}
        className={cn(
          'flex h-8 w-full rounded-md border border-border bg-background px-2.5 pr-7 text-xs text-foreground',
          'placeholder:text-muted-foreground focus-visible:border-primary focus-visible:outline-none disabled:opacity-50',
          invalid && 'border-destructive',
        )}
      />
      <button
        type="button"
        {...cb.getToggleButtonProps({ disabled, tabIndex: -1 })}
        aria-label={`Open ${ariaLabel ?? 'list'}`}
        className="absolute top-0 right-0 flex h-8 w-7 items-center justify-center text-muted-foreground"
      >
        <ChevronDown size={14} />
      </button>
      <ul
        {...cb.getMenuProps()}
        className={cn(
          'absolute z-50 mt-1 max-h-60 w-full overflow-y-auto rounded-md border border-border bg-card py-1 shadow-lg',
          !open && 'hidden',
        )}
      >
        {open && rows.length === 0 && (
          <li className="px-2.5 py-1.5 text-xs text-muted-foreground">
            {options.length === 0 ? 'No options' : 'No match'}
          </li>
        )}
        {open &&
          rows.map((o, i) => (
            <li
              key={o.value}
              data-value={o.value === NONE ? '' : o.value}
              {...cb.getItemProps({ item: o, index: i, disabled: o.disabled })}
              className={cn(
                'flex cursor-pointer items-baseline gap-2 px-2.5 py-1.5 text-xs',
                cb.highlightedIndex === i && 'bg-background text-foreground',
                o.disabled && 'cursor-not-allowed opacity-50',
              )}
            >
              <span className="flex-1 truncate">{o.label}</span>
              {o.hint && <span className="shrink-0 text-[11px] text-muted-foreground">{o.hint}</span>}
            </li>
          ))}
      </ul>
    </div>
  );
}
```

import { describe, expect, it } from 'vitest';
import { useState } from 'react';
import { render, screen } from '@testing-library/react';
import userEvent from '@testing-library/user-event';
import { Dialog } from './dialog.tsx';

/**
 * v0.4g Task 2: quick-create opens a create dialog on top of the dialog
 * whose picker asked for it. The HTML specification keeps modal dialogs on
 * a stack, so this is supposed to work — but eleven call sites depend on
 * it, so it is pinned rather than assumed.
 */
describe('a dialog opened from inside a dialog', () => {
  function Nested() {
    const [inner, setInner] = useState(false);
    return (
      <Dialog open onClose={() => {}} title="Outer">
        <button type="button" onClick={() => setInner(true)}>Open inner</button>
        <Dialog open={inner} onClose={() => setInner(false)} title="Inner">
          <button type="button" onClick={() => setInner(false)}>Close inner</button>
        </Dialog>
      </Dialog>
    );
  }

  it('shows both, and closing the inner one leaves the outer one open', async () => {
    const user = userEvent.setup();
    render(<Nested />);
    await user.click(screen.getByRole('button', { name: 'Open inner' }));
    expect(screen.getByText('Inner')).toBeVisible();
    expect(screen.getByText('Outer')).toBeVisible();
    await user.click(screen.getByRole('button', { name: 'Close inner' }));
    expect(screen.queryByText('Inner')).not.toBeInTheDocument();
    expect(screen.getByText('Outer')).toBeVisible();
  });
});

```ts
import userEvent from '@testing-library/user-event';
import type { screen as rtlScreen, within as rtlWithin } from '@testing-library/react';

type Scope = typeof rtlScreen | ReturnType<typeof rtlWithin>;

/**
 * Chooses an option from a ui/Select (v0.4g). It replaced
 * `userEvent.selectOptions`, which drives a native select element and
 * stopped working when the last one was removed.
 *
 * `option` takes either the visible label or `{ value }`. The value form
 * exists because every call this helper replaced passed an option's value,
 * and because two options may legitimately share a label — two credentials
 * named "deploy" of different kinds, two hosts of the same name in
 * different zones.
 */
export async function pickOption(scope: Scope, label: string, option: string | { value: string }): Promise<void> {
  const user = userEvent.setup();
  await user.click(scope.getByLabelText(label));
  const rows = scope.getAllByRole('option');
  const wanted =
    typeof option === 'string'
      ? rows.find((r) => r.textContent?.includes(option))
      : rows.find((r) => r.getAttribute('data-value') === option.value);
  if (!wanted) {
    const seen = rows.map((r) => `${r.getAttribute('data-value')}=${r.textContent}`).join(', ');
    throw new Error(
      `pickOption: no option ${JSON.stringify(option)} in "${label}". The list held: ${seen || '(nothing)'}`,
    );
  }
  await user.click(wanted);
}
```

import { expect, type Locator, type Page } from '@playwright/test';

/**
 * The Playwright half of src/test/pickOption.ts (v0.4g): choose an option
 * from a ui/Select. Replaces `locator.selectOption`, which only drives a
 * native select element.
 *
 * `scope` is a page or a dialog locator, exactly like the getByLabel calls
 * this replaced. `option` is the visible label, or `{ value }` for the
 * eight call sites that passed an option value and for lists where two
 * options legitimately share a label.
 */
export async function pickOption(
  scope: Page | Locator,
  label: string,
  option: string | { value: string },
): Promise<void> {
  await scope.getByLabel(label, { exact: true }).click();
  const row =
    typeof option === 'string'
      ? scope.getByRole('option', { name: option, exact: true })
      : scope.locator(`[role="option"][data-value="${option.value}"]`);
  await expect(row).toBeVisible();
  await row.click();
}

After:

```tsx

  options={credentials.filter((c) => c.kind === 'git_key').map((c) => ({ value: c.id, label: c.name }))}
  value={credentialId}

```

The empty `<option value="">` becomes `placeholder`, keeping its exact wording. An `aria-label` stays an `aria-label`. A select with no empty option gets no `placeholder`. Delete the file's now-unused `const SELECT = ...` if nothing else uses it.
