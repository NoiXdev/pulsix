# Pulsix v0.1 Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running, tested Pulsix manager with multi-tenant organizations, password + TOTP + passkey authentication, scoped API tokens, hosts with capability flags and tags, audit log, OpenAPI explorer, an embedded React SPA shell and a single-node Docker Compose setup.

**Architecture:** One Go module with `cmd/manager` as the entry point and focused packages under `internal/`. PostgreSQL 18 + TimescaleDB is the only stateful service; every domain table carries `org_id` and is protected by row-level security. The HTTP API is built with huma v2 on chi so the OpenAPI 3.1 document is generated from Go types; the SPA talks only to that API and is embedded into the manager binary.

**Tech Stack:** Go 1.27, chi v5, huma v2, pgx v5, sqlc, goose v3, testcontainers-go, golang.org/x/crypto/argon2, pquerna/otp, go-webauthn/webauthn, React 19 + TypeScript + Vite (current stable), TanStack Router/Query, Tailwind v4, Vitest, Playwright.

## Global Constraints

- Language: all code, comments, commit messages, docs in English. Chat with the user in German.
- Commits: Conventional Commits (`feat`, `fix`, `docs`, `refactor`, `test`, `build`, `ci`, `chore`), footer `Co-Authored-By: Claude Opus 5 <noreply@anthropic.com>`. Commit only what a task tells you to commit.
- Go 1.27, module path `github.com/noixdev/pulsix`. `gofmt` + `golangci-lint` clean. `go test -race ./...` green before every commit.
- IDs are UUIDv7 (`github.com/google/uuid`, `uuid.Must(uuid.NewV7())`). Table and column names `snake_case`.
- Every domain table has `org_id uuid NOT NULL` and an RLS policy keyed on `current_setting('pulsix.org_id', true)`.
- Migrations are additive only. Never drop or rename in a migration inside this plan.
- Secrets at rest use AES-256-GCM with the 32-byte `PULSIX_MASTER_KEY`; passwords argon2id; API tokens stored as SHA-256 hashes.
- Environment variables are prefixed `PULSIX_`. Required: `PULSIX_DATABASE_URL`, `PULSIX_MASTER_KEY`, `PULSIX_PUBLIC_URL`.
- Coverage gates in CI: Go packages ≥ 80 % lines; `internal/auth`, `internal/tenancy`, `internal/db` ≥ 90 %; SPA ≥ 70 %. Entry-point wiring under `cmd/` and packages that are entirely machine-generated are excluded, and a generated package is recognised by every one of its non-test files carrying a `Code generated … DO NOT EDIT.` header, never by its path — so a hand-written file dropped into such a directory brings the whole package back under the gate. The behaviour a generated package encodes is covered by tests in the package that owns it: the sqlc wrappers in `internal/db/gen` carry hand-written SQL, and `internal/db` tests every one of those queries against a real database.
- Status colours are reserved for states in the SPA; the accent `#00E5FF` is for actions and selection. Tokens come from `brand/tokens.css`.
- **Dependencies are current, never stale.** Every dependency uses the newest stable
  release, or the active LTS line where a project publishes one. Version numbers and
  image tags written in this plan are a floor and an example, not a pin: at
  implementation time verify the newest version (`go list -m -versions <mod>`,
  `npm view <pkg> version`, the registry's tag list) and use that, then record in your
  report what you pinned and why. Never introduce a deprecated API; when a library
  deprecates what this plan's sample code calls, use the documented replacement and
  report the substitution.
- Repository stays private. Public copy (README of the future public repo) contains no tech-stack terms; internal docs may.
- One version for manager, worker and agent: a single `vX.Y.Z` tag releases everything (Task 16's release workflow builds both images and, from v0.3, the agent binaries). No per-component tags.
- **Layering (from `CLAUDE.md`):** handlers in `internal/api` only decode, call a service and encode. Business rules live in domain services (`internal/<domain>/service.go`) that depend on a `Store` interface declared next to them; sqlc code is wrapped by a store adapter. Unit tests use fakes of the `Store`; integration tests use the real store. Constructors inject dependencies; no package globals; time via an injected `Clock`.
- End-user documentation for every user-visible feature goes to `NoiXdev/noix-docs` (docs.noix.dev) on the `pulsix` branch in the same work item.

## Decisions taken in this plan

- **OpenAPI toolchain: huma v2.** Spec §20 left huma vs. ogen open. huma generates OpenAPI 3.1 from Go structs with no codegen step, validates requests, and mounts on chi. ogen would force spec-first editing for every change. Decision recorded here; revisit only if huma's schema output blocks a client generator later.
- **Router: chi v5**, middleware stack `RequestID → Logger → Recoverer → auth`. chi 5.3
  deprecates `middleware.RealIP` because it mutates `r.RemoteAddr` from a spoofable
  header; where a later task needs the client IP (audit log, rate limiting) it uses
  chi's `ClientIPFromXFFTrustedProxies` plus `GetClientIP` with the proxy list from
  configuration, never a blind `X-Forwarded-For` read.
- **Database access: sqlc** (queries in `internal/db/queries/*.sql`, generated code in `internal/db/gen`) on top of pgx v5. Handwritten pgx only for `COPY` and `LISTEN/NOTIFY` (later milestones).
- **Testing:** every package has `_test.go` files; integration tests use one shared Postgres container per test binary via `internal/db/testdb`.

```go
// Package api builds the HTTP handler for the Pulsix manager.
package api

import (
	"context"
	"net/http"

	"github.com/danielgtaylor/huma/v2"
	"github.com/danielgtaylor/huma/v2/adapters/humachi"
	"github.com/go-chi/chi/v5"
	"github.com/go-chi/chi/v5/middleware"
)

// Deps carries everything the handlers need. Later tasks add fields.
type Deps struct{}

type healthOutput struct {
	Body struct {
		Status string `json:"status" example:"ok"`
	}
}

// New returns the root http.Handler: chi router + huma API under /api/v1.
func New(deps Deps) http.Handler {
	r := chi.NewRouter()
	r.Use(middleware.RequestID, middleware.RealIP, middleware.Logger, middleware.Recoverer)

	r.Get("/healthz", func(w http.ResponseWriter, _ *http.Request) {
		w.Header().Set("Content-Type", "application/json")
		_, _ = w.Write([]byte(`{"status":"ok"}`))
	})

	cfg := huma.DefaultConfig("Pulsix API", "0.1.0")
	cfg.OpenAPIPath = "/api/openapi"
	cfg.DocsPath = "" // explorer is mounted by Task 6
	hapi := humachi.New(r, cfg)
	registerRoutes(hapi, deps)
	return r
}

// registerRoutes is extended by later tasks (one register* call per resource).
func registerRoutes(hapi huma.API, deps Deps) {
	huma.Get(hapi, "/api/v1/health", func(ctx context.Context, _ *struct{}) (*healthOutput, error) {
		out := &healthOutput{}
		out.Body.Status = "ok"
		return out, nil
	})
}
```

```go
// Package config loads manager settings from PULSIX_* environment variables.
package config

import (
	"encoding/hex"
	"errors"
	"fmt"
	"net/url"
)

// Config is the validated manager configuration.
type Config struct {
	Listen       string
	DatabaseURL  string
	PublicURL    string
	StatusDomain string
	MasterKey    [32]byte
}

// Load reads and validates configuration. getenv is injected for tests.
func Load(getenv func(string) string) (Config, error) {
	var cfg Config
	cfg.Listen = getenv("PULSIX_LISTEN")
	if cfg.Listen == "" {
		cfg.Listen = ":8080"
	}
	cfg.DatabaseURL = getenv("PULSIX_DATABASE_URL")
	if cfg.DatabaseURL == "" {
		return cfg, errors.New("PULSIX_DATABASE_URL is required")
	}
	cfg.PublicURL = getenv("PULSIX_PUBLIC_URL")
	u, err := url.Parse(cfg.PublicURL)
	if err != nil || u.Scheme == "" || u.Host == "" {
		return cfg, errors.New("PULSIX_PUBLIC_URL must be an absolute URL")
	}
	cfg.StatusDomain = getenv("PULSIX_STATUS_DOMAIN")
	key, err := hex.DecodeString(getenv("PULSIX_MASTER_KEY"))
	if err != nil || len(key) != 32 {
		return cfg, fmt.Errorf("PULSIX_MASTER_KEY must be 64 hex characters (32 bytes)")
	}
	copy(cfg.MasterKey[:], key)
	return cfg, nil
}
```

`internal/db/db.go`:

```go
// Package db owns the connection pool, migrations and the per-org transaction helper.
package db

import (
	"context"
	"embed"
	"fmt"

	"github.com/google/uuid"
	"github.com/jackc/pgx/v5"
	"github.com/jackc/pgx/v5/pgxpool"
	"github.com/jackc/pgx/v5/stdlib"
	"github.com/pressly/goose/v3"
)

//go:embed migrations/*.sql
var migrations embed.FS

// migrationLockKey is the PostgreSQL advisory lock that serializes migrations
// across manager instances. The value is arbitrary but must never change.
const migrationLockKey = 7256

// DB wraps the pgx pool.
type DB struct{ pool *pgxpool.Pool }

// Open connects and pings.
func Open(ctx context.Context, url string) (*DB, error) {
	pool, err := pgxpool.New(ctx, url)
	if err != nil {
		return nil, fmt.Errorf("open pool: %w", err)
	}
	if err := pool.Ping(ctx); err != nil {
		return nil, fmt.Errorf("ping: %w", err)
	}
	return &DB{pool: pool}, nil
}

// Pool exposes the underlying pool for sqlc-generated code.
func (d *DB) Pool() *pgxpool.Pool { return d.pool }

// Close releases the pool.
func (d *DB) Close() { d.pool.Close() }

// Migrate applies all embedded goose migrations under an advisory lock.
func (d *DB) Migrate(ctx context.Context) error {
	goose.SetBaseFS(migrations)
	if err := goose.SetDialect("postgres"); err != nil {
		return err
	}
	sqlDB := stdlib.OpenDBFromPool(d.pool)
	defer sqlDB.Close()

	// The advisory lock is session-scoped, so it must be taken and released on
	// one pinned connection: a database/sql pool may hand the unlock to a
	// different session, which would leave the lock held. goose migrates on
	// other connections of the same pool, which is fine — the lock coordinates
	// manager instances, not individual statements.
	conn, err := sqlDB.Conn(ctx)
	if err != nil {
		return fmt.Errorf("pin migration connection: %w", err)
	}
	defer conn.Close()
	if _, err := conn.ExecContext(ctx, `SELECT pg_advisory_lock($1)`, migrationLockKey); err != nil {
		return fmt.Errorf("acquire migration lock: %w", err)
	}
	defer func() {
		// Runs even when ctx is already cancelled; closing conn would release
		// the lock anyway, this makes the release explicit.
		_, _ = conn.ExecContext(context.WithoutCancel(ctx), `SELECT pg_advisory_unlock($1)`, migrationLockKey)
	}()
	if err := goose.UpContext(ctx, sqlDB, "migrations"); err != nil {
		return fmt.Errorf("apply migrations: %w", err)
	}
	return nil
}

// WithOrg runs fn in a transaction scoped to orgID via the RLS setting.
func (d *DB) WithOrg(ctx context.Context, orgID uuid.UUID, fn func(pgx.Tx) error) error {
	tx, err := d.pool.Begin(ctx)
	if err != nil {
		return err
	}
	defer tx.Rollback(ctx) //nolint:errcheck
	if _, err := tx.Exec(ctx, `SELECT set_config('pulsix.org_id', $1, true)`, orgID.String()); err != nil {
		return err
	}
	if err := fn(tx); err != nil {
		return err
	}
	return tx.Commit(ctx)
}
```

```go
// Package testdb starts one TimescaleDB container per test binary.
package testdb

import (
	"context"
	"sync"
	"testing"
	"time"

	"github.com/testcontainers/testcontainers-go"
	"github.com/testcontainers/testcontainers-go/modules/postgres"
	"github.com/testcontainers/testcontainers-go/wait"

	"github.com/noixdev/pulsix/internal/db"
)

var (
	once sync.Once
	url  string
	errC error
)

func start() {
	ctx := context.Background()
	c, err := postgres.Run(ctx, "timescale/timescaledb:2.30.0-pg18",
		postgres.WithDatabase("pulsix"), postgres.WithUsername("pulsix"), postgres.WithPassword("pulsix"),
		testcontainers.WithWaitStrategy(wait.ForLog("database system is ready to accept connections").WithOccurrence(2).WithStartupTimeout(90*time.Second)))
	if err != nil {
		errC = err
		return
	}
	url, errC = c.ConnectionString(ctx, "sslmode=disable")
}

// Open returns a migrated DB. All tables are truncated when the test ends.
func Open(t *testing.T) *db.DB {
	t.Helper()
	once.Do(start)
	if errC != nil {
		t.Fatalf("start postgres container: %v", errC)
	}
	ctx := context.Background()
	d, err := db.Open(ctx, url)
	if err != nil {
		t.Fatal(err)
	}
	if err := d.Migrate(ctx); err != nil {
		t.Fatal(err)
	}
	t.Cleanup(func() {
		// A failing truncate must be loud: silently leaving rows behind makes
		// the next test fail somewhere unrelated.

			FOR r IN SELECT tablename FROM pg_tables WHERE schemaname = 'public' AND tablename <> 'goose_db_version' LOOP
```

```go
// Package crypto wraps AES-256-GCM sealing with the instance master key.
package crypto

import (
	"crypto/aes"
	"crypto/cipher"
	"crypto/rand"
	"errors"
	"io"
)

// Box seals and opens secrets with one key.
type Box struct{ aead cipher.AEAD }

// NewBox builds an AES-256-GCM box.
func NewBox(key [32]byte) *Box {
	block, err := aes.NewCipher(key[:])
	if err != nil {
		panic(err) // key length is fixed by the type
	}
	aead, err := cipher.NewGCM(block)
	if err != nil {
		panic(err)
	}
	return &Box{aead: aead}
}

// Seal returns nonce || ciphertext.
func (b *Box) Seal(plain []byte) ([]byte, error) {
	nonce := make([]byte, b.aead.NonceSize())
	if _, err := io.ReadFull(rand.Reader, nonce); err != nil {
		return nil, err
	}
	return b.aead.Seal(nonce, nonce, plain, nil), nil
}

// Open reverses Seal and fails on any tampering.
func (b *Box) Open(sealed []byte) ([]byte, error) {
	n := b.aead.NonceSize()
	if len(sealed) < n {
		return nil, errors.New("sealed value too short")
	}
	return b.aead.Open(nil, sealed[:n], sealed[n:], nil)
}
```

```go
// Package auth implements passwords, sessions, TOTP, passkeys and API tokens.
package auth

import (
	"crypto/rand"
	"crypto/subtle"
	"encoding/base64"
	"errors"
	"fmt"
	"strings"

	"golang.org/x/crypto/argon2"
)

const (
	argonTime    = 3
	argonMemory  = 64 * 1024
	argonThreads = 2
	argonKeyLen  = 32
)

// HashPassword returns a PHC-formatted argon2id hash.
func HashPassword(pw string) (string, error) {
	salt := make([]byte, 16)
	if _, err := rand.Read(salt); err != nil {
		return "", err
	}
	key := argon2.IDKey([]byte(pw), salt, argonTime, argonMemory, argonThreads, argonKeyLen)
	enc := base64.RawStdEncoding.EncodeToString
	return fmt.Sprintf("$argon2id$v=19$m=%d,t=%d,p=%d$%s$%s", argonMemory, argonTime, argonThreads, enc(salt), enc(key)), nil
}

// VerifyPassword checks pw against a hash produced by HashPassword.
func VerifyPassword(hash, pw string) (bool, error) {
	parts := strings.Split(hash, "$")
	if len(parts) != 6 || parts[1] != "argon2id" {
		return false, errors.New("unsupported hash format")
	}
	var m, t uint32
	var p uint8
	if _, err := fmt.Sscanf(parts[3], "m=%d,t=%d,p=%d", &m, &t, &p); err != nil {
		return false, err
	}
	salt, err := base64.RawStdEncoding.DecodeString(parts[4])
	if err != nil {
		return false, err
	}
	want, err := base64.RawStdEncoding.DecodeString(parts[5])
	if err != nil {
		return false, err
	}
	got := argon2.IDKey([]byte(pw), salt, t, m, p, uint32(len(want)))
	return subtle.ConstantTimeCompare(got, want) == 1, nil
}
```

```go
package auth

import (
	"context"
	"crypto/rand"
	"crypto/sha256"
	"crypto/subtle"
	"encoding/base64"
	"errors"
	"strings"
	"time"

	"github.com/google/uuid"

	"github.com/noixdev/pulsix/internal/db/gen"
)

// SessionTTL is the cookie session lifetime.
const SessionTTL = 12 * time.Hour

// ErrUnauthenticated is returned when no valid credential is present.
var ErrUnauthenticated = errors.New("unauthenticated")

// Principal identifies the caller of a request.
type Principal struct {
	UserID        uuid.UUID
	SessionID     uuid.UUID
	TokenID       *uuid.UUID
	InstanceAdmin bool
	MFAComplete   bool
}

// Sessions stores cookie sessions as id + hashed secret.
type Sessions struct{ q *gen.Queries }

// NewSessions builds the session store.
func NewSessions(q *gen.Queries) *Sessions { return &Sessions{q: q} }

// Create inserts a session and returns the cookie value "<id>.<secret>".
func (s *Sessions) Create(ctx context.Context, userID uuid.UUID, mfaComplete bool) (uuid.UUID, string, error) {
	id := uuid.Must(uuid.NewV7())
	secret := make([]byte, 32)
	if _, err := rand.Read(secret); err != nil {
		return uuid.Nil, "", err
	}
	sum := sha256.Sum256(secret)
	err := s.q.CreateSession(ctx, gen.CreateSessionParams{
		ID: id, UserID: userID, SecretHash: sum[:], MfaComplete: mfaComplete,
		ExpiresAt: time.Now().Add(SessionTTL),
	})
	if err != nil {
		return uuid.Nil, "", err
	}
	return id, id.String() + "." + base64.RawURLEncoding.EncodeToString(secret), nil
}

// Lookup validates a cookie value.
func (s *Sessions) Lookup(ctx context.Context, cookie string) (Principal, error) {
	idStr, secretStr, ok := strings.Cut(cookie, ".")
	if !ok {
		return Principal{}, ErrUnauthenticated
	}
	id, err := uuid.Parse(idStr)
	if err != nil {
		return Principal{}, ErrUnauthenticated
	}
	secret, err := base64.RawURLEncoding.DecodeString(secretStr)
	if err != nil {
		return Principal{}, ErrUnauthenticated
	}
	row, err := s.q.GetSession(ctx, id)
	if err != nil {
		return Principal{}, ErrUnauthenticated
	}
	sum := sha256.Sum256(secret)
	if subtle.ConstantTimeCompare(sum[:], row.SecretHash) != 1 {
		return Principal{}, ErrUnauthenticated
	}
	return Principal{UserID: row.UserID, SessionID: row.ID, InstanceAdmin: row.InstanceAdmin, MFAComplete: row.MfaComplete}, nil
}

// MarkMFAComplete upgrades a session after a successful second factor.
func (s *Sessions) MarkMFAComplete(ctx context.Context, id uuid.UUID) error {
	return s.q.MarkSessionMFAComplete(ctx, id)
}

// Revoke ends a session.
func (s *Sessions) Revoke(ctx context.Context, id uuid.UUID) error { return s.q.RevokeSession(ctx, id) }
```

```go
package auth

import (
	"context"
	"net/http"
)

type ctxKey struct{}

// CookieName is the session cookie.
const CookieName = "pulsix_session"

// WithPrincipal stores p in ctx.
func WithPrincipal(ctx context.Context, p Principal) context.Context {
	return context.WithValue(ctx, ctxKey{}, p)
}

// FromContext returns the principal set by a middleware.
func FromContext(ctx context.Context) (Principal, bool) {
	p, ok := ctx.Value(ctxKey{}).(Principal)
	return p, ok
}

// CookieMiddleware resolves the session cookie into a Principal when valid.
func CookieMiddleware(s *Sessions) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			if c, err := r.Cookie(CookieName); err == nil {
				if p, err := s.Lookup(r.Context(), c.Value); err == nil {
					r = r.WithContext(WithPrincipal(r.Context(), p))
				}
			}
			next.ServeHTTP(w, r)
		})
	}
}

func SetCookie(w http.ResponseWriter, value string, secure bool) {
	http.SetCookie(w, &http.Cookie{
		Name: CookieName, Value: value, Path: "/", HttpOnly: true, Secure: secure,
		SameSite: http.SameSiteLaxMode, MaxAge: int(SessionTTL.Seconds()),
	})
}

// ClearCookie removes the session cookie.
func ClearCookie(w http.ResponseWriter) {
	http.SetCookie(w, &http.Cookie{Name: CookieName, Value: "", Path: "/", HttpOnly: true, MaxAge: -1})
```

```go
	"context"
	"errors"
	"fmt"

	"github.com/google/uuid"
)

// User is the service-level view of a user row.
type User struct {
	ID            uuid.UUID
	Email         string
	DisplayName   string
	PasswordHash  *string
	InstanceAdmin bool
}

// Sentinel errors mapped to HTTP status by the transport layer.
var (
	ErrNotFound           = errors.New("not found")
	ErrInvalidCredentials = errors.New("invalid credentials")
)

// Store is what the auth service needs from persistence.
type Store interface {
	GetUserByEmail(ctx context.Context, email string) (User, error)
	GetUserByID(ctx context.Context, id uuid.UUID) (User, error)
}

// SessionStore is the subset of *Sessions the service uses (fakeable in tests).
type SessionStore interface {
	Create(ctx context.Context, userID uuid.UUID, mfaComplete bool) (uuid.UUID, string, error)
	Revoke(ctx context.Context, id uuid.UUID) error
}

// MFAChecker reports whether a user must complete a second factor.
type MFAChecker interface {
	Enabled(ctx context.Context, userID uuid.UUID) (bool, error)
}

// NoMFA is the checker used before TOTP exists.
type NoMFA struct{}

// Enabled always returns false.
func (NoMFA) Enabled(context.Context, uuid.UUID) (bool, error) { return false, nil }

// Service implements login, logout and "who am I".
type Service struct {
	store    Store
	sessions SessionStore
	mfa      MFAChecker
}

// NewService wires the dependencies.
func NewService(store Store, sessions SessionStore, mfa MFAChecker) *Service {
	return &Service{store: store, sessions: sessions, mfa: mfa}
}

// LoginResult is what the transport needs to answer a login.
type LoginResult struct {
	Cookie      string
	MFARequired bool
}

// Login verifies the password and opens a session.
//
// When the address is unknown the password is still verified against a fixed
// dummy hash before returning: otherwise an unknown address answers in
// microseconds while a known one spends ~100 ms in argon2, which enumerates
// accounts at one request each.
func (s *Service) Login(ctx context.Context, email, password string) (LoginResult, error) {
	u, err := s.store.GetUserByEmail(ctx, email)
	if err != nil || u.PasswordHash == nil {
		_, _ = VerifyPassword(dummyHash, password)
		return LoginResult{}, ErrInvalidCredentials
	}
	ok, err := VerifyPassword(*u.PasswordHash, password)
	if err != nil {
		return LoginResult{}, fmt.Errorf("verify password: %w", err)
	}
	if !ok {
		return LoginResult{}, ErrInvalidCredentials
	}
	mfaRequired, err := s.mfa.Enabled(ctx, u.ID)
	if err != nil {
		return LoginResult{}, fmt.Errorf("check mfa: %w", err)
	}
	_, cookie, err := s.sessions.Create(ctx, u.ID, !mfaRequired)
	if err != nil {
		return LoginResult{}, fmt.Errorf("create session: %w", err)
	}
	return LoginResult{Cookie: cookie, MFARequired: mfaRequired}, nil
}

// Logout revokes the caller's session.
func (s *Service) Logout(ctx context.Context, p Principal) error {
	return s.sessions.Revoke(ctx, p.SessionID)
}

// Me returns the caller's user.
func (s *Service) Me(ctx context.Context, p Principal) (User, error) {
	return s.store.GetUserByID(ctx, p.UserID)
}
```

```go
type loginInput struct {
	Body struct {
		Email    string `json:"email" format:"email" minLength:"3"`
		Password string `json:"password" minLength:"8"`
	}
}

type loginOutput struct {
	SetCookie http.Cookie `header:"Set-Cookie"`
	Body      struct {
		MFARequired bool `json:"mfa_required"`
	}
}

type meOutput struct {
	Body struct {
		User struct {
			ID          string `json:"id"`
			Email       string `json:"email"`
			DisplayName string `json:"display_name"`
		} `json:"user"`
		MFAComplete   bool `json:"mfa_complete"`
		InstanceAdmin bool `json:"instance_admin"`
	}
}

type logoutOutput struct {
	SetCookie http.Cookie `header:"Set-Cookie"`
}

func registerAuthRoutes(hapi huma.API, deps Deps) {
	huma.Post(hapi, "/api/v1/auth/login", func(ctx context.Context, in *loginInput) (*loginOutput, error) {
		res, err := deps.Auth.Login(ctx, in.Body.Email, in.Body.Password)
		if err != nil {
			return nil, mapAuthErr(err)
		}
		out := &loginOutput{}
		out.SetCookie = sessionCookie(res.Cookie, deps.Secure)
		out.Body.MFARequired = res.MFARequired
		return out, nil
	})

	huma.Post(hapi, "/api/v1/auth/logout", func(ctx context.Context, _ *struct{}) (*logoutOutput, error) {
		if p, ok := auth.FromContext(ctx); ok {
			_ = deps.Auth.Logout(ctx, p)
		}
		return &logoutOutput{SetCookie: http.Cookie{Name: auth.CookieName, Value: "", Path: "/", MaxAge: -1, HttpOnly: true}}, nil
	})

	huma.Get(hapi, "/api/v1/auth/me", func(ctx context.Context, _ *struct{}) (*meOutput, error) {
		p, err := requireSession(ctx)
		if err != nil {
			return nil, err
		}
		u, err := deps.Auth.Me(ctx, p)
		if err != nil {
			return nil, mapAuthErr(err)
		}
		out := &meOutput{}
		out.Body.User.ID, out.Body.User.Email, out.Body.User.DisplayName = u.ID.String(), u.Email, u.DisplayName
		out.Body.MFAComplete, out.Body.InstanceAdmin = p.MFAComplete, p.InstanceAdmin
		return out, nil
	})

func sessionCookie(value string, secure bool) http.Cookie {
	return http.Cookie{Name: auth.CookieName, Value: value, Path: "/", HttpOnly: true, Secure: secure,
		SameSite: http.SameSiteLaxMode, MaxAge: int(auth.SessionTTL.Seconds())}
}

// requireSession returns the principal or a 401.
func requireSession(ctx context.Context) (auth.Principal, error) {
	p, ok := auth.FromContext(ctx)
	if !ok {
		return p, huma.Error401Unauthorized("login required")
	}
	return p, nil
}

// mapAuthErr translates service sentinels to HTTP errors. Unmapped errors are
// logged server-side and answered generically: huma serialises a returned error
// into the response body, so passing one through leaks internal detail — a
// corrupt password hash, a raw driver error — to unauthenticated clients.
func mapAuthErr(ctx context.Context, err error) error {
	switch {
	case errors.Is(err, auth.ErrInvalidCredentials):
		return huma.Error401Unauthorized("invalid credentials")
	case errors.Is(err, auth.ErrNotFound):
		return huma.Error401Unauthorized("login required")
	default:
		slog.ErrorContext(ctx, "unhandled auth error", "err", err)
		return huma.Error500InternalServerError("internal error")
	}
}
```

```go
package auth

import (
	"context"
	"crypto/rand"
	"crypto/sha256"
	"encoding/base32"
	"errors"
	"strings"
	"time"

	"github.com/google/uuid"
	"github.com/pquerna/otp"
	"github.com/pquerna/otp/totp"

	"github.com/noixdev/pulsix/internal/crypto"
	"github.com/noixdev/pulsix/internal/db/gen"
)

// TOTP manages time-based one-time passwords and recovery codes.
type TOTP struct {
	q      *gen.Queries
	box    *crypto.Box
	issuer string
}

// NewTOTP builds the service. issuer is shown in authenticator apps.
func NewTOTP(q *gen.Queries, box *crypto.Box, issuer string) *TOTP {
	return &TOTP{q: q, box: box, issuer: issuer}
}

// BeginEnrol creates an unconfirmed secret and returns it for the QR code.
func (t *TOTP) BeginEnrol(ctx context.Context, userID uuid.UUID, email string) (string, string, error) {
	key, err := totp.Generate(totp.GenerateOpts{Issuer: t.issuer, AccountName: email, Algorithm: otp.AlgorithmSHA1})
	if err != nil {
		return "", "", err
	}
	sealed, err := t.box.Seal([]byte(key.Secret()))
	if err != nil {
		return "", "", err
	}
	if err := t.q.UpsertTOTPSecret(ctx, gen.UpsertTOTPSecretParams{UserID: userID, SecretSealed: sealed}); err != nil {
		return "", "", err
	}
	return key.Secret(), key.URL(), nil
}

// ConfirmEnrol validates the first code, activates TOTP and issues 8 recovery codes.
func (t *TOTP) ConfirmEnrol(ctx context.Context, userID uuid.UUID, code string) ([]string, error) {
	ok, err := t.verifyAndConsume(ctx, userID, code, false)
	if err != nil {
		return nil, err
	}
	if !ok {
		return nil, errors.New("invalid code")
	}
	if err := t.q.ConfirmTOTP(ctx, userID); err != nil {
		return nil, err
	}
	if err := t.q.ReplaceRecoveryCodes(ctx, userID); err != nil {
		return nil, err
	}
	codes := make([]string, 8)
	for i := range codes {
		raw := make([]byte, 10)
		if _, err := rand.Read(raw); err != nil {
			return nil, err
		}
		c := strings.ToLower(base32.StdEncoding.WithPadding(base32.NoPadding).EncodeToString(raw))
		codes[i] = c[:5] + "-" + c[5:10] + "-" + c[10:15]
		sum := sha256.Sum256([]byte(codes[i]))
		if err := t.q.InsertRecoveryCode(ctx, gen.InsertRecoveryCodeParams{UserID: userID, CodeHash: sum[:]}); err != nil {
			return nil, err
		}
	}
	return codes, nil
}

// Verify checks a code against a confirmed secret and rejects replays within a step.
func (t *TOTP) Verify(ctx context.Context, userID uuid.UUID, code string) (bool, error) {
	return t.verifyAndConsume(ctx, userID, code, true)
}

func (t *TOTP) verifyAndConsume(ctx context.Context, userID uuid.UUID, code string, requireConfirmed bool) (bool, error) {
	row, err := t.q.GetTOTPSecret(ctx, userID)
	if err != nil {
		return false, nil
	}
	if requireConfirmed && !row.ConfirmedAt.Valid {
		return false, nil
	}
	secret, err := t.box.Open(row.SecretSealed)
	if err != nil {
		return false, err
	}
	now := time.Now()
	if !totp.Validate(code, string(secret)) {
		return false, nil
	}
	step := now.Unix() / 30
	n, err := t.q.SetTOTPLastStep(ctx, gen.SetTOTPLastStepParams{UserID: userID, LastUsedStep: step})
	if err != nil {
		return false, err
	}
	return n == 1, nil // 0 rows means this step was already consumed
}

// VerifyRecovery consumes one recovery code.
func (t *TOTP) VerifyRecovery(ctx context.Context, userID uuid.UUID, code string) (bool, error) {
	sum := sha256.Sum256([]byte(strings.ToLower(strings.TrimSpace(code))))
	n, err := t.q.UseRecoveryCode(ctx, gen.UseRecoveryCodeParams{UserID: userID, CodeHash: sum[:]})
	return n == 1, err
}

// Enabled reports whether the user has a confirmed TOTP secret.
func (t *TOTP) Enabled(ctx context.Context, userID uuid.UUID) (bool, error) {
	row, err := t.q.GetTOTPSecret(ctx, userID)
	if err != nil {
		return false, nil
	}
	return row.ConfirmedAt.Valid, nil
}

// Disable removes the secret and recovery codes.
func (t *TOTP) Disable(ctx context.Context, userID uuid.UUID) error {
	if err := t.q.ReplaceRecoveryCodes(ctx, userID); err != nil {
		return err
	}
	return t.q.DeleteTOTP(ctx, userID)
}
```

```go
	huma.Post(hapi, "/api/v1/auth/totp/enrol", func(ctx context.Context, _ *struct{}) (*totpEnrolOutput, error) {
		p, err := requireSession(ctx)
		if err != nil {
			return nil, err
		}
		u, err := deps.Auth.Me(ctx, p)
		if err != nil {
			return nil, mapAuthErr(err)
		}
		secret, url, err := deps.TOTP.BeginEnrol(ctx, p.UserID, u.Email)

			return nil, err
		}
		out := &totpEnrolOutput{}
		out.Body.Secret, out.Body.OTPAuthURL = secret, url
		return out, nil
	})

	huma.Post(hapi, "/api/v1/auth/totp/confirm", func(ctx context.Context, in *codeInput) (*recoveryOutput, error) {
		p, err := requireSession(ctx)
		if err != nil {
			return nil, err
		}
		codes, err := deps.TOTP.ConfirmEnrol(ctx, p.UserID, in.Body.Code)
		if err != nil {
			return nil, huma.Error400BadRequest("invalid code")
		}
		out := &recoveryOutput{}
		out.Body.RecoveryCodes = codes
		return out, nil
	})

	huma.Post(hapi, "/api/v1/auth/totp/verify", func(ctx context.Context, in *codeInput) (*struct{}, error) {
		p, err := requireSession(ctx)
		if err != nil {
			return nil, err
		}
		var ok bool
		if in.Body.RecoveryCode != "" {
			ok, err = deps.TOTP.VerifyRecovery(ctx, p.UserID, in.Body.RecoveryCode)
		} else {
			ok, err = deps.TOTP.Verify(ctx, p.UserID, in.Body.Code)
		}
		if err != nil {
			return nil, err
		}
		if !ok {
			return nil, huma.Error401Unauthorized("invalid code")
		}
		return nil, deps.Sessions.MarkMFAComplete(ctx, p.SessionID)
	})

	huma.Delete(hapi, "/api/v1/auth/totp", func(ctx context.Context, in *codeInput) (*struct{}, error) {

		if err != nil {
			return nil, err
		}

		if err != nil || !ok {
			return nil, huma.Error401Unauthorized("invalid code")
		}
		return nil, deps.TOTP.Disable(ctx, p.UserID)
	})
```

**Interfaces:**
- Produces: `auth.AnyEnabled(checkers ...MFAChecker) MFAChecker`, a combinator reporting a second factor as present when **any** checker does and propagating the first error it sees (failing closed). `auth.NewService` receives `auth.AnyEnabled(totp, passkeys)`, because a passkey is a second factor: without it, an account whose only factor is a passkey gets an MFA-complete session from a stolen password alone, which also defeats `requireMFAComplete` on the passkey management routes. `*auth.Passkeys` therefore satisfies `MFAChecker` by reporting whether the user has at least one credential. A password login by such a user yields a pending session, and the passkey login endpoints issue the full session — that is the step-up.
- Produces: `auth.PasskeyStore` interface: `ListCredentials(ctx, userID) ([]Credential, error)`, `AddCredential(ctx, userID, name string, c Credential) error`, `UpdateCredentialCounter(ctx, credentialID []byte, counter uint32) error`, `FindUserByCredentialID(ctx, credentialID []byte) (userID uuid.UUID, error)`, `PutCeremony(ctx, id uuid.UUID, kind string, userID *uuid.UUID, data []byte, expiresAt time.Time) error`, `TakeCeremony(ctx, id uuid.UUID) (kind string, userID *uuid.UUID, data []byte, error)` (deletes on read).

```go
func (w waUser) WebAuthnName() string                       { return w.u.Email }
func (w waUser) WebAuthnDisplayName() string                { return w.u.DisplayName }

func toWebauthn(cs []Credential) []webauthn.Credential {
	out := make([]webauthn.Credential, 0, len(cs))
	for _, c := range cs {
		tr := make([]protocol.AuthenticatorTransport, len(c.Transports))
		for i, t := range c.Transports {
			tr[i] = protocol.AuthenticatorTransport(t)
		}
		out = append(out, webauthn.Credential{ID: c.CredentialID, PublicKey: c.PublicKey, AttestationType: c.Attestation, Transport: tr,
			Authenticator: webauthn.Authenticator{SignCount: c.SignCount}, Flags: webauthn.CredentialFlags{BackupEligible: c.BackupEligible}})
	}
	return out
}

func (p *Passkeys) BeginRegistration(ctx context.Context, userID uuid.UUID) (json.RawMessage, uuid.UUID, error) {

	if err != nil {
		return nil, uuid.Nil, err

		exclude = append(exclude, c.Descriptor())
	}

	if err != nil {
		return nil, uuid.Nil, err

	if err != nil {
		return nil, uuid.Nil, err
	}

	return raw, cid, err
}

// FinishRegistration verifies the attestation and stores the credential.
func (p *Passkeys) FinishRegistration(ctx context.Context, userID, ceremonyID uuid.UUID, name string, response json.RawMessage) error {
	cUser, sd, err := p.takeCeremony(ctx, ceremonyID, "register")
	if err != nil {
		return err
	}
	if cUser == nil || *cUser != userID {
		return ErrNotFound
	}
	u, err := p.loadUser(ctx, userID)
	if err != nil {
		return err
	}
	parsed, err := protocol.ParseCredentialCreationResponseBody(bytes.NewReader(response))
	if err != nil {
		return fmt.Errorf("parse attestation: %w", err)
	}
	cred, err := p.wa.CreateCredential(u, *sd, parsed)
	if err != nil {
		return fmt.Errorf("verify attestation: %w", err)
	}
	tr := make([]string, len(cred.Transport))
	for i, t := range cred.Transport {
		tr[i] = string(t)
	}
	return p.store.AddCredential(ctx, userID, name, Credential{
		ID: uuid.Must(uuid.NewV7()), Name: name, CredentialID: cred.ID, PublicKey: cred.PublicKey, Attestation: cred.AttestationType,
		Transports: tr, SignCount: cred.Authenticator.SignCount, BackupEligible: cred.Flags.BackupEligible,
	})
}

func (p *Passkeys) BeginLogin(ctx context.Context) (json.RawMessage, uuid.UUID, error) {
	opts, sd, err := p.wa.BeginDiscoverableLogin()
	if err != nil {
		return nil, uuid.Nil, err
	}
	cid, err := p.saveCeremony(ctx, "login", nil, sd)
	if err != nil {
		return nil, uuid.Nil, err
	}
	raw, err := json.Marshal(opts)
	return raw, cid, err
}

// FinishLogin verifies the assertion and opens an MFA-complete session.
func (p *Passkeys) FinishLogin(ctx context.Context, ceremonyID uuid.UUID, response json.RawMessage) (string, error) {
	_, sd, err := p.takeCeremony(ctx, ceremonyID, "login")
	if err != nil {
		return "", err
	}
	parsed, err := protocol.ParseCredentialRequestResponseBody(bytes.NewReader(response))
	if err != nil {
		return "", fmt.Errorf("parse assertion: %w", err)
	}
	var found waUser
	handler := func(rawID, userHandle []byte) (webauthn.User, error) {
		userID, err := p.store.FindUserByCredentialID(ctx, rawID)
		if err != nil {
			return nil, err
		}
		if !bytes.Equal(userHandle, userID[:]) {
			return nil, errors.New("user handle mismatch")
		}
		found, err = p.loadUser(ctx, userID)
		return found, err
	}
	cred, err := p.wa.ValidateDiscoverableLogin(handler, *sd, parsed)
	if err != nil {
		return "", ErrInvalidCredentials
	}
	if err := p.store.UpdateCredentialCounter(ctx, cred.ID, cred.Authenticator.SignCount); err != nil {
		return "", err
	}
	_, cookie, err := p.sessions.Create(ctx, found.u.ID, true)
	return cookie, err
}

// List returns the user's passkeys for the settings page.
func (p *Passkeys) List(ctx context.Context, userID uuid.UUID) ([]Credential, error) {
	return p.store.ListCredentials(ctx, userID)
}
```

```go
package auth

// Token is a stored API token (never the secret).
type Token struct {
	ID         uuid.UUID
	UserID     uuid.UUID
	OrgID      uuid.UUID
	Name       string
	Role       string
	ExpiresAt  *time.Time
	LastUsedAt *time.Time
	CreatedAt  time.Time
}

// TokenScope pins a bearer token to one org and a maximum role.
type TokenScope struct {
	OrgID uuid.UUID
	Role  string
}

// TokenStore persists API tokens.
type TokenStore interface {
	Insert(ctx context.Context, t Token, secretHash []byte) error
	GetByHash(ctx context.Context, secretHash []byte, now time.Time) (Token, bool /*instanceAdmin*/, error)
	ListForOrg(ctx context.Context, orgID uuid.UUID) ([]Token, error)
	Revoke(ctx context.Context, orgID, id uuid.UUID) error
	TouchLastUsed(ctx context.Context, id uuid.UUID, at time.Time) error
}

// Tokens creates and resolves bearer tokens.
type Tokens struct {
	store TokenStore
	now   func() time.Time
}

// NewTokens wires the store and clock.
func NewTokens(store TokenStore, now func() time.Time) *Tokens { return &Tokens{store: store, now: now} }

const tokenPrefix = "pxt_"

// Create returns the plaintext token once.
func (t *Tokens) Create(ctx context.Context, userID, orgID uuid.UUID, name, role string, expiresAt *time.Time) (string, Token, error) {
	secret := make([]byte, 32)
	if _, err := rand.Read(secret); err != nil {
		return "", Token{}, err
	}
	sum := sha256.Sum256(secret)
	tok := Token{ID: uuid.Must(uuid.NewV7()), UserID: userID, OrgID: orgID, Name: name, Role: role, ExpiresAt: expiresAt, CreatedAt: t.now()}
	if err := t.store.Insert(ctx, tok, sum[:]); err != nil {
		return "", Token{}, err
	}
	plain := tokenPrefix + base64.RawURLEncoding.EncodeToString(secret)
	return plain, tok, nil
}

// Resolve validates a plaintext token.
func (t *Tokens) Resolve(ctx context.Context, plain string) (Principal, TokenScope, error) {
	if !strings.HasPrefix(plain, tokenPrefix) {
		return Principal{}, TokenScope{}, ErrUnauthenticated
	}
	secret, err := base64.RawURLEncoding.DecodeString(strings.TrimPrefix(plain, tokenPrefix))
	if err != nil {
		return Principal{}, TokenScope{}, ErrUnauthenticated
	}
	sum := sha256.Sum256(secret)
	tok, admin, err := t.store.GetByHash(ctx, sum[:], t.now())
	if err != nil {
		return Principal{}, TokenScope{}, ErrUnauthenticated
	}
	_ = t.store.TouchLastUsed(ctx, tok.ID, t.now())
	id := tok.ID
	return Principal{UserID: tok.UserID, TokenID: &id, InstanceAdmin: admin, MFAComplete: true}, TokenScope{OrgID: tok.OrgID, Role: tok.Role}, nil
}

// List and Revoke delegate to the store.
func (t *Tokens) List(ctx context.Context, orgID uuid.UUID) ([]Token, error) { return t.store.ListForOrg(ctx, orgID) }
func (t *Tokens) Revoke(ctx context.Context, orgID, id uuid.UUID) error      { return t.store.Revoke(ctx, orgID, id) }
```

```go
// BearerMiddleware resolves "Authorization: Bearer pxt_…" tokens.
func BearerMiddleware(t *Tokens) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			if h := r.Header.Get("Authorization"); strings.HasPrefix(h, "Bearer ") {
				if p, scope, err := t.Resolve(r.Context(), strings.TrimPrefix(h, "Bearer ")); err == nil {
					ctx := WithPrincipal(r.Context(), p)
					r = r.WithContext(context.WithValue(ctx, scopeKey{}, scope))
				} else {
					http.Error(w, `{"title":"Unauthorized","status":401}`, http.StatusUnauthorized)
					return
				}
			}
			next.ServeHTTP(w, r)
		})
	}
```

```go
// Package tenancy implements organizations, memberships, roles and invitations.
package tenancy

// Role is an org membership role.
type Role string

// Roles from most to least privileged.
const (
	RoleOwner    Role = "owner"
	RoleAdmin    Role = "admin"
	RoleOperator Role = "operator"
	RoleViewer   Role = "viewer"
)

// Permission names an action checked by the API layer.
type Permission string

// Permissions used in v0.1.
const (
	PermOrgManage     Permission = "org.manage"
	PermOrgDelete     Permission = "org.delete"
	PermMembersManage Permission = "members.manage"
	PermTokensManage  Permission = "tokens.manage"
	PermHostsRead     Permission = "hosts.read"
	PermHostsWrite    Permission = "hosts.write"
	PermAuditRead     Permission = "audit.read"
)

var rank = map[Role]int{RoleViewer: 1, RoleOperator: 2, RoleAdmin: 3, RoleOwner: 4}

var matrix = map[Permission]Role{ // minimum role per permission
	PermOrgManage:     RoleAdmin,
	PermOrgDelete:     RoleOwner,
	PermMembersManage: RoleAdmin,
	PermTokensManage:  RoleAdmin,
	PermHostsRead:     RoleViewer,
	PermHostsWrite:    RoleOperator,
	PermAuditRead:     RoleOperator,
}

// Allows reports whether role may perform perm.
func Allows(role Role, perm Permission) bool {
	r, ok := rank[role]
	min, known := matrix[perm]
	return ok && known && r >= rank[min]
}

// Lower returns the less privileged of two roles (unknown roles rank lowest).
func Lower(a, b Role) Role {
	if rank[a] <= rank[b] {
		return a
	}
	return b
}

// Valid reports whether r is a known role.
func Valid(r Role) bool { _, ok := rank[r]; return ok }
```

```go
// Invite creates the invitation and e-mails the link.
func (s *Service) Invite(ctx context.Context, orgID, byUserID uuid.UUID, email string, role Role) (Invite, error) {
	if !Valid(role) || role == RoleOwner {
		return Invite{}, fmt.Errorf("invite role %q: %w", role, ErrForbidden)
	}
	secret := make([]byte, 24)
	if _, err := rand.Read(secret); err != nil {
		return Invite{}, err
	}
	token := base64.RawURLEncoding.EncodeToString(secret)
	sum := sha256.Sum256([]byte(token))
	inv := Invite{ID: uuid.Must(uuid.NewV7()), OrgID: orgID, Email: strings.ToLower(email), Role: role, InvitedBy: byUserID, ExpiresAt: s.now().Add(InviteTTL), Token: token}
	if err := s.store.InsertInvite(ctx, inv, sum[:]); err != nil {
		return Invite{}, fmt.Errorf("insert invite: %w", err)
	}
	org, err := s.store.GetOrgByID(ctx, orgID)
	if err != nil {
		return Invite{}, err
	}
	body := fmt.Sprintf("You have been invited to %s on Pulsix as %s.\n\nAccept: %s/invite/%s\n\nThe link expires in 7 days.", org.Name, role, s.publicURL, token)
	if err := s.mailer.Send(ctx, inv.Email, "Invitation to "+org.Name, body); err != nil {
		return Invite{}, fmt.Errorf("send invite mail: %w", err)
	}
	return inv, nil
}

// AcceptInvite creates or updates the user and joins the org.
func (s *Service) AcceptInvite(ctx context.Context, token, displayName, password string) (uuid.UUID, uuid.UUID, error) {
	sum := sha256.Sum256([]byte(token))
	inv, err := s.store.TakeInvite(ctx, sum[:], s.now())
	if err != nil {
		return uuid.Nil, uuid.Nil, ErrNotFound
	}
	hash, err := auth.HashPassword(password)
	if err != nil {
		return uuid.Nil, uuid.Nil, err
	}
	u, err := s.store.GetUserByEmail(ctx, inv.Email)
	switch {
	case errors.Is(err, ErrNotFound):
		u = User{ID: uuid.Must(uuid.NewV7()), Email: inv.Email, DisplayName: displayName, PasswordHash: &hash}
		if err := s.store.CreateUser(ctx, u); err != nil {
			return uuid.Nil, uuid.Nil, err
		}
	case err != nil:
		return uuid.Nil, uuid.Nil, err
	default:
		if u.PasswordHash == nil { // user row created by a previous invite, never logged in
			if err := s.store.SetUserPasswordAndName(ctx, u.ID, hash, displayName); err != nil {
				return uuid.Nil, uuid.Nil, err
			}
		}
	}
	if err := s.store.AddMembership(ctx, inv.OrgID, u.ID, inv.Role); err != nil {
		return uuid.Nil, uuid.Nil, err
	}
	return u.ID, inv.OrgID, nil
}

// ChangeRole enforces: only owners grant/revoke owner; never demote the last owner.
func (s *Service) ChangeRole(ctx context.Context, orgID, actor, target uuid.UUID, role Role) error {
	if !Valid(role) {
		return ErrForbidden
	}
	actorRole, err := s.store.GetMembership(ctx, orgID, actor)
	if err != nil {
		return ErrNotMember
	}
	current, err := s.store.GetMembership(ctx, orgID, target)
	if err != nil {
		return ErrNotFound
	}
	if (role == RoleOwner || current == RoleOwner) && actorRole != RoleOwner {
		return ErrForbidden
	}
	if current == RoleOwner && role != RoleOwner {
		n, err := s.store.CountOwners(ctx, orgID)
		if err != nil {
			return err
		}
		if n <= 1 {
			return ErrLastOwner
		}
	}
	return s.store.UpdateMembershipRole(ctx, orgID, target, role)
}
```

```go
package api

// Scope is the authorized (org, user, effective role) for a request.
type Scope struct {
	OrgID  uuid.UUID
	UserID uuid.UUID
	Role   tenancy.Role
}

// requireOrg resolves the org by slug and checks perm for the caller.
func requireOrg(ctx context.Context, deps Deps, orgSlug string, perm tenancy.Permission) (Scope, error) {
	p, ok := auth.FromContext(ctx)
	if !ok {
		return Scope{}, huma.Error401Unauthorized("login required")
	}
	if p.TokenID == nil && !p.MFAComplete {
		return Scope{}, huma.Error403Forbidden("second factor required")
	}
	org, err := deps.Tenancy.GetOrgBySlug(ctx, orgSlug)
	if err != nil {
		return Scope{}, huma.Error404NotFound("organization not found")
	}
	role, err := deps.Tenancy.MembershipOf(ctx, org.ID, p.UserID)
	if err != nil {
		return Scope{}, huma.Error403Forbidden("not a member")
	}
	if ts, ok := auth.TokenScopeFromContext(ctx); ok {
		if ts.OrgID != org.ID {
			return Scope{}, huma.Error403Forbidden("token is scoped to another organization")
		}
		role = tenancy.Lower(role, tenancy.Role(ts.Role))
	}
	if !tenancy.Allows(role, perm) {
		return Scope{}, huma.Error403Forbidden("insufficient role")
	}
	return Scope{OrgID: org.ID, UserID: p.UserID, Role: role}, nil
}

// requireInstanceAdmin gates instance-level routes.
func requireInstanceAdmin(ctx context.Context) (auth.Principal, error) {
	p, err := requireSession(ctx)
	if err != nil {
		return p, err
	}
	if !p.InstanceAdmin {
		return p, huma.Error403Forbidden("instance admin required")
	}
	return p, nil
}

// mapTenancyErr converts service sentinels.
func mapTenancyErr(err error) error {
	switch {
	case errors.Is(err, tenancy.ErrNotFound):
		return huma.Error404NotFound("not found")
	case errors.Is(err, tenancy.ErrForbidden), errors.Is(err, tenancy.ErrNotMember):
		return huma.Error403Forbidden(err.Error())
	case errors.Is(err, tenancy.ErrLastOwner), errors.Is(err, tenancy.ErrSlugTaken):
		return huma.Error409Conflict(err.Error())
	default:
		return err
	}
}
```

- [ ] **Step 4: Embed the SPA in the manager**

`internal/web/embed.go`:

```go
// Package web serves the built SPA from the binary.
package web

import (
	"embed"
	"io/fs"
	"net/http"
	"strings"
)

//go:embed all:dist
var dist embed.FS

// Handler serves static assets and falls back to index.html for app routes.
func Handler() http.Handler {
	sub, err := fs.Sub(dist, "dist")
	if err != nil {
		panic(err)
	}
	files := http.FS(sub)
	fileServer := http.FileServer(files)
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if strings.HasPrefix(r.URL.Path, "/api/") {
			http.NotFound(w, r)
			return
		}
		if f, err := files.Open(r.URL.Path); err == nil {
			_ = f.Close()
			fileServer.ServeHTTP(w, r)
			return
		}
		r.URL.Path = "/"
		fileServer.ServeHTTP(w, r)
	})
}
```

The Makefile copies `web/dist` to `internal/web/dist` before `go build`; commit a placeholder `internal/web/dist/index.html` so `go test` works without a frontend build. `embed_test.go`: `/` and `/o/acme/hosts` return the index HTML; `/api/v1/nothing` returns 404.
