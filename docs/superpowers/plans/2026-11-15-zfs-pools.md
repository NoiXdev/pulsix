**Goal:** A `zfs` agent check plugin reporting each ZFS pool's health, space, errors, scrub/resilver progress and scrub age.

**Architecture:** A new package `internal/agent/checks/plugins/zfs/` (command runner seam over `zpool`/`zfs`, text parsers, Linux source, stub elsewhere), registered next to `raid`; a descriptor in `internal/checkplugins` drives the manager, rules catalogue, API enums and SPA.

**Tech Stack:** Go (`os/exec`), React/TypeScript SPA (fixture and texts only).

**Spec:** `docs/superpowers/specs/2026-11-15-zfs-pools-design.md`

## Global Constraints

- Plugin `zfs`, parameter `pools`, metrics exactly as the spec's table; item `""` carries only `zfs.pools` and host-level errors.
- Linux only; never a shell; `LC_ALL=C`; 30 s per call, 60 s per collection, 1 MiB stdout per call; no test runs the real `zpool` or `zfs`.
- Repo English; public docs never name the tech stack.
- Never `go test ./...`; per package `go test -race -timeout 900s` (`internal/api` `-timeout 1800s`, run WHOLE once after adding the plugin); `golangci-lint run` clean, plus `GOOS=windows golangci-lint run ./internal/agent/...` and `GOOS=linux|darwin|windows go vet ./internal/agent/...`.
- Conventional Commits; footer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; commit on the branch only; no push, tag, stash or other state-changing git.

## Review Focus

1. A suspended or hanging pool: `zpool status` blocks — the 30 s / 60 s bounds hold and the error lands on the right metrics (Task 1 test with a blocking fake runner).
2. Error counters double-counted or missed across tree levels and the `logs`/`cache`/`special`/`spares` groups (Task 1 fixtures).
3. A pool that never finished a scrub (new pool, canceled scrub, resilver only) never produces an error on `zfs.scrub_age_days` while `zfs get` works (Task 1).
4. Locale/format drift: older releases' `%` suffixes, abbreviated counters, `scanned … of` without a percentage (Task 1 fixtures).
5. A pool name unfit as an item, and a pool vanishing between `list` and `status` (Task 1).
