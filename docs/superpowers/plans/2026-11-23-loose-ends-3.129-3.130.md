## Rulings (controller's calls)
- Outline names: keyword-only tasks, `{role: ~}`, `import_playbook: [x]` and any other value that yields no usable name fall back to the kind label the outline already uses for unnamed entries. `async`, `poll`, `delay`, `retries`, `until` (and the other task keywords the walker already knows) are never a task's module/name; `action:`/`local_action:` name the task after their module (first word of a string value, or the `module` key of a mapping).
- Outline tags: an entry carries its effective tag set as today, but the total tags emitted across one outline are bounded (pick a budget that keeps the JSON for the worst case under ~1 MiB, e.g. `maxOutlineTagsTotal`); past it, entries carry only their own tags. `tagsOf` checks the list length before reading items.
- Outline caps: the response says when a cap cut it short (`truncated: true` on the outline, plus which cap if cheap), and the SPA shows one sentence for it.
- Outline schema names: the API layer gets its own DTO types for the outline so the published schema names are API names, not the domain package's; JSON shape unchanged.
- Draft size: the service validates the size (not only the handler).
- `host_counts`: two inventory names that map to one host add up instead of overwriting.
- Worker texts: `ctx.Err()` checked between files; once the budget is full a file is `stat`ed and left out as `budget` without being opened when it cannot fit (a later file that fits is still kept, as today).
- Manager: a path present in both `playbook_texts` and `playbook_texts_left_out` keeps the text and drops the reason. A playbook left out by a cap with no earlier text is stored and served with its real reason, not `not_sent`. A text kept from an earlier sync is served with an explicit boolean (e.g. `from_earlier_sync: true`) beside its commit, and the SPA says so from the flag, not from an empty commit.
- `If-Match: *` matches any current revision (RFC 9110) in the shared helper, for every revisioned route; tests on one template route and the playbook route.
- SPA: repository-derived queries (the repository text with them) refetch when a sync job completes; the content query retries transient errors (network, 5xx) but not 404/422; a 404 that is not the "not synced yet" answer (an older server without the route) reads as "this server does not serve the repository text yet"; a failing re-read after a 412 shows an error instead of an unhandled rejection.
